# myhealth design lock

The requested target is Hex, specifically the Refero style reference
https://styles.refero.design/style/3e32db74-a61d-4e72-93b8-1fb949af2c00.
The public reference was read when the Refero connector reported no subscription.

| Decision | Evidence | Adaptation |
|---|---|---|
| Near-white #fffcfc canvas, #01011b ink | Hex palette | Full application canvas |
| Fine #dbd7da borders, 3px controls, 6px panels | Hex control/surface roles | Compact, notebook-like dashboard |
| Light italic serif with compact sans | Hex typography | Serif overview title, plain sans data labels; system fallbacks support Cyrillic |
| Violet #6f63b7 and teal #21918c | Hex data visualization roles | Chart content only |
| Outlined, unfilled actions | Hex button rule | Login, download, range controls |
| Red values and visible reference bounds | User requirement | Red out-of-range values; pale reference bands and explicit boundary labels |
| Search, grouped navigation, exact date tables | User's complete medical history task | No invented metrics or generated clinical interpretations |

No stock imagery, marketing cards, gradients, giant rounded controls or colored CTA fills.
Charts are native SVG data marks, not decorative fake illustrations.
