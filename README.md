# myhealth

Личный архив анализов: графики, таблицы, референсные полосы и история качественных результатов.
Визуальное направление — Hex. Интерфейс на русском, поддерживает телефон и клавиатуру.

## Данные и пароль

В репозитории и на GitHub Pages хранится только зашифрованный архив `vault.json`.
Исходный Markdown, пароль и расшифрованный JSON в Git не добавляются.
AES-256-GCM; PBKDF2-SHA256, 600 000 итераций; случайные 32-байтная соль и 12-байтный IV.
Пароль не отправляется серверу и не сохраняется в браузере. После перезагрузки нужен новый вход.
Не используйте короткий пароль: зашифрованный файл публичен и доступен для офлайн-перебора.
Смена пароля не отзывает ранее скачанные копии старого зашифрованного архива.

## Проверки и локальная сборка

Node.js 22+, без установки зависимостей.

```sh
npm test
npm run build -- --source /absolute/path/to/analyses.md
npm run dev
```

При первой сборке генерируется длинный пароль, показанный один раз в выводе сборки.
Для обновления задайте прежний пароль в `MYHEALTH_PASSWORD`, затем повторите сборку.
Храните пароль отдельно от репозитория. Не передавайте его аргументом команды и не коммитьте `.env`.
В GitHub Settings / Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
После отправки обновлений в `main` GitHub Pages опубликует содержимое корневой папки.

## Достоверность отображения

- Каждая непустая запись сохраняется вместе с датой и исходным текстом.
- Новые нормы из примечаний связываются с результатами 20.11.2026; старые нормы — из исходной таблицы.
- Красный цвет означает выход за указанный диапазон, а не диагноз.
- Диапазоны меняются по датам; полоса на графике ступенчатая.
- Пороговые результаты `<` / `>` не превращаются в точные числа и не соединяются линией.
- Для качественных результатов используется история по датам, для единичных — одна точка.
- Гормоны с неоднозначными диапазонами показываются без произвольно выбранной полосы.
- Несопоставимый масштаб старой записи MCHC сохраняется в таблице и исключается из линии до проверки единиц.
- Полный исходный файл скачивается только после открытия архива.
